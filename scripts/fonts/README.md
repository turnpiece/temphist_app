# Fonts

`Sora-Variable.ttf` — Sora, a variable font (weight axis 100–800), used by
`compose_appstore_screenshots.py` for the promo/screenshot headlines.

Sora is licensed under the SIL Open Font License 1.1. This copy was extracted
from the font embedded in `assets/promos/html/` (the 1.2 promo templates), so
the screenshots use the same typeface as those.
